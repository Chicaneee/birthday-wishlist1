# Birthday Wishlist

Сайт-вишлист для дня рождения: можно выбрать конкретный подарок для конюшни или открыть отдельную банку Monobank.

## Публикация на GitHub Pages

Сайт готов к публикации как обычный статический сайт. Для GitHub Pages нужны:

- `index.html`
- `styles.css`
- `app.js`
- папка `assets/`

После загрузки файлов в репозиторий нужно включить GitHub Pages:

1. Открыть репозиторий на GitHub.
2. Перейти в `Settings` -> `Pages`.
3. В `Build and deployment` выбрать `Deploy from a branch`.
4. Выбрать ветку `main` и папку `/root`.
5. Нажать `Save`.

Публичная ссылка будет выглядеть примерно так:

```text
https://chicaneee.github.io/birthday-wishlist1/
```

## Важное про бронь

На GitHub Pages сайт не запускает локальный Python-сервер. Поэтому кнопка брони на публичной версии будет сохранять бронь только в браузере конкретного человека. Чтобы бронь была общей для всех гостей, нужно позже подключить отдельное онлайн-хранилище.

## Что менять

- `app.js` — список подарков, цены, описания, ссылки на товары и банки Monobank.
- `assets/` — изображения для верхнего экрана и карточек.
- `index.html` — основные тексты разделов.
- `styles.css` — цвета, отступы и внешний вид.

## Где поменять банки Monobank

У каждой цели в `app.js` есть поле:

```js
monoJarUrl: "https://send.monobank.ua/jar/...",
```

Там стоит ссылка на конкретную банку. Если поменяешь банку, замени ссылку в этом поле.
